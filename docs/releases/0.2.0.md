# 0.2.0

Release candidate. Requires macOS 27+.

- Adds LocalAgent with 3-Scene Story Creator and Shekhar Joke Generator.
- Uses GitHub release ranges for AgentAtom and TerminalAgentSession and the
  unpublished sibling KhabarwaaniAgent package.
- Supports Codex, Claude, Antigravity, Grok, and on-device Apple Intelligence.
- Disables unavailable providers and exposes package runtime settings.
- Displays final JSON, readable output, execution metadata, and actionable errors.
- Supports cancellation and preserves inputs/results when switching tabs.

Validated locally: 119 deterministic tests pass. Live input/output completed for
Codex (both tools), Antigravity (story), and Apple Intelligence (story).
Grok launches but its account reports a usage quota limit. Claude is not installed
and appears disabled. Validation covers execution and data flow; humans review
agent content.

Dynamic agent catalogs and schema-generated input forms are planned for 1.0.0.
