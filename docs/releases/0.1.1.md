# 0.1.1

Released 11 October 2026 from `a46536d`: [v0.1.1](https://github.com/Khabarwaani/script-maker-mac/releases/tag/v0.1.1). DMG publishing verified.

- Shared AI selection in Settings: provider, model and reasoning, serialized as one identifier; five recent selections.
- Library uses the shared model without a duplicate selection control.
- Editing and accepting refinement save a new story with the same title, a new UUID and timestamp, and an incremented subtitle number. Originals remain available.
- Native multiple story selection, selected/all deletion confirmations, copy/share/media menus, and item removal with Undo.
- Google Drive text export, Telegram share composer, and standard macOS sharing destinations.
- Icon-only Hashtag and News update controls aligned with their headings.
- Standard macOS progress indicators across Studio and Library.
- Window title: `Script Maker (v0.1.1 - <build commit>)`.
- Detailed future backend contracts for Library updates, refinement, media and model catalogs.

Validation: 58 native unit tests, green develop CI, release build and native control checks. No real messages or cloud uploads sent during verification.

Server Library/model endpoints remain future backend work. Google Drive uses a native save dialog for a Drive-synced folder or manual upload; Telegram opens a composer for the user to choose the recipient and send.
