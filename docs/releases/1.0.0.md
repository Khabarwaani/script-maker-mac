# 1.0.0

Requires macOS 27+ and Xcode 27+ for development.

Version prepared; release publication pending.

- Dynamic local-agent discovery, version selection and schema-generated forms.
- Library stories require only a title; scripts, generation details and media are optional.
- Direct HTTP news search and publisher images, with locally derived hashtags and no AI or ScriptMakerServer dependency.
- Editable headlines with refreshed related content; failed searches retain saved stories and show actionable errors.
- Integrated Telegram bot uploads with optional video and opt-in group sending, reusing ScriptMaker's local configuration.
- Integrated Google Drive / Sheets video uploads through Khabarwaani Operations, with local Google authentication and saved upload receipts.

The Library feature passed all 109 tests in GitHub Actions before this version bump.
No tag or release DMG has been published for 1.0.0.
