# 1.2.0

Requires macOS 27+. Build 10.

### KhabarwaaniAgent 1.4.2 & ThreeSceneStoryCreator 2.2.1
- Integrated `KhabarwaaniAgent 1.4.2` and updated `ThreeSceneStoryCreator` to version `2.2.1`.
- Spoken dialogue defaults to natural everyday Hindi/Hinglish in Devanagari script with English descriptions.
- Story facts, actions, settings, and timeframes are aligned with real news event chronology.
- Pacing calibrated to 25–35 words per scene (2.5–3.5 words/second) within strict 10-second scene bounds.

### Selectable Script Refinement Execution Modes
- Added 4 selectable execution presets in Settings and Script Chat, defaulting to **Fast & Clean**:
  - **Fast & Clean (Recommended / Default)**: App-launch temp workspace, `persistentStdio`, single loopable turn, memory cleared (`session.clearMemory()`) before and after each request.
  - **Strict Ephemeral**: Isolated temp directory per request, cleaned up immediately.
  - **Retained Memory**: App-launch temp workspace, subprocess session memory preserved across turns.
  - **Daemon**: Persistent background agent daemon process.
