# 0.1.0

- Native Studio dropdown menus with matching field styling and full-field clicks.
- Reference colors, appearance settings, aligned controls, and persistent scrollbars.
- Local JSON generation with a configurable simulation delay; server URL settings without artificial timing.
- Continuous and stepwise workflows finish at integration and final validation.
- Each generated story has a UUID, generation number, timestamp, and its own Library entry.
- Readable screenplay details, native copy menu, share action, source links, and hashtags when supplied.
- Local story deletion and Delete all; server deletion still requires backend support.
- Window title shows version and build commit.

Validation: Mac build, unit tests, and app-control checks for menus, generation, Library selection, copy feedback, and both themes.
