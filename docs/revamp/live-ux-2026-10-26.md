## Issues found

- Initial discovery refresh could overwrite a manual topic handed from Researcher
  to Pipeline. Fixed source guards and rechecked handoff through the app.
- Research event location could become the discovery country. Resolve only known
  regions; otherwise retain the configured discovery location.
- Refined screenplay saved under a generic title. Recover the screenplay title,
  with the earlier generated story title as fallback.
- Default pipeline polish expanded spoken dialogue. Default instruction now
  explicitly preserves scene duration/word budget and prohibits word-count growth.
  Explicit 30-word Library refinement produced shorter scenes with the manual
  ending intact. Prompt constraints are not deterministic timing validation.
- Script Detail chat history disappeared on restart while the script remained.
  Added optional Codable history to the scene, populated on save and restored on
  selection. Existing scenes without history still load. A fresh sound-direction
  update and its generated script remained visible after quitting and relaunching.
