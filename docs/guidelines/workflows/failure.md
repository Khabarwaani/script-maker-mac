# Failures

GitHub Actions CI (`xcodebuild test`) is the gate. Run tests locally only when diagnosing
and reproducing a failure reported by CI. Report the failure verbatim before fixing.

Triage:

| Defect | Action |
| :--- | :--- |
| Regression from edit | Fix the implementation. |
| Intentional requirement/UX change | Update tests in the same PR; cover the new behavior, never weaken assertions. No separate test-defect issue. |
| Unrelated defective test | Do not edit or weaken the test; file a bug: title, test file path, why the code is correct, type `Bug` (`--type`, never `--label`). |
| Xcode project broken (missing file refs) | Fix project.pbxproj in the same PR — every new source file must be in Sources. |

Issue attribution: append `_Generated by <model>_` or `_Generated by human and <model>_` to the issue body.
