| Defect | Action | Report Params |
| :--- | :--- | :--- |
| `ci-cd/*`, `git/*`, `dev/*` defect / outdated CLI | Do not bypass; update existing issue or report bug | Title, script path, error, required fix, type `Bug` (`--type`, never `--label`) |
| Regression from edit | Fix implementation | N/A |
| Intentional requirement/UX change | Update tests in the same PR; cover the new behavior, never weaken assertions | No separate test-defect issue |
| Baseline fail (`./runut --baseline <target>`) | Note in PR; do not expand scope | N/A |
| Unrelated defective test (`tests/*`) | Do not edit or weaken test; update existing issue or report bug | Title, test file path, why code is correct, test defect, type `Bug` (`--type`, never `--label`) |
